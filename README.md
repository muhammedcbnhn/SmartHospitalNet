# SmartCareNet: IoT-Enabled Smart Hospital Network Topology

## 🏥 About the Project
This project presents a comprehensive, secure, and highly available smart hospital network topology simulated in **Cisco Packet Tracer**. It is designed to meet the critical demands of modern healthcare facilities by providing a scalable infrastructure that includes IoT device integration, strict network isolation, and centralized management. 

All background configurations, routing, and switching setups are fully implemented and ready to test.

## ✨ Key Features
* **VLAN Segmentation & Network Isolation:** The network is logically divided to ensure security, performance, and data privacy across different hospital departments:
  * `VLAN 10`: Server Farm
  * `VLAN 20`: Doctors
  * `VLAN 30`: Patient Rooms
  * `VLAN 40`: Operating Rooms
  * `VLAN 70`: Emergency Service
  * `VLAN 80`: Security Room
  * `VLAN 1`: Guest Network
* **IoT Integration:** Smart sensors and IoT devices are seamlessly integrated into patient and operating rooms for real-time monitoring and automation.
* **Security Architecture:** Configured with robust Firewalls, IP Camera security systems, and strict VLAN isolation rules to protect sensitive medical data.
* **High Availability & Performance:** Built with a hierarchical design using Core Routers, L3 Switches, and Access Switches connected via Fiber Optic and Copper links.
* **Wireless Connectivity:** Features Wireless Access Points (WAPs) and Wireless LAN Controllers (WLC) for seamless mobility across the facility.

## 🛠️ Technologies & Protocols Used
* Cisco Packet Tracer
* Network Routing & Switching (L2/L3)
* VLAN & Inter-VLAN Routing
* Firewall Configuration
* IoT Networking & Sensor Integration
* WLAN & WLC Management
